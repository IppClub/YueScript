## Tentang

<img width="1071" height="1500" decoding="async" src="/image/mascot/electrichearts_20260211A_yuescript_xiaoyu.png" alt="Xiaoyu si Kelinci Siber" style="max-width: 420px; width: 100%; border-radius: 12px; margin-bottom: 1.5em;" />

Xiaoyu (小玉, "giok kecil") adalah seekor kelinci siber dan maskot resmi proyek YueScript. Ia duduk di atas bulan sabit, menulis YueScript di laptopnya.

Gelar lengkapnya adalah Xiaoyu si Kelinci Siber (机兔小玉). Ia mencerminkan apa yang dituju YueScript: bersih, ekspresif, dan sedikit menyenangkan.

**[Tyson Tan](https://tysontan.com)** merancang dan mengilustrasikan Xiaoyu untuk proyek ini secara gratis. Kami berterima kasih atas kontribusinya.
